This documentation in this folder provides reusable guidance on defining enhanced agile deliverables, milestone payments, and surge work across HHS open source procurements. It is useful for all team members working on the project to have clarity on the definitions of these terms.

The information is not procurement sensitive, contains no confidential information, and can be fully public. It explains concepts and does not discuss contractual requirements for a specific contract.

This folder contains example language that can be used by other procurements. Agile deliverables and milestone payments, as defined here, provide a flexible and effective framework for ensuring that government contractors deliver the outcomes that their clients seek, while maintaining flexibility and adaptability in planning.

Every four months, the government client and the contractor use the agile deliverable framework to agree on critical outcomes that are highest priority for the next four months. Milestone payments are issued based on whether the contractor delivers on those outcomes.
