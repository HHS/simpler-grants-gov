# Welcome to Simpler.Grants.Gov Design System Storybook

The [Simpler.Grants.gov](http://simpler.grants.gov/) dev team uses [Storybook](https://storybook.js.org/) to document our [Next.js](https://nextjs.org/) components. The `main` branch of our [GitHub project](https://github.com/HHS/simpler-grants-gov) automatically deploys this documentation to [GitHub Pages](https://hhs.github.io/simpler-grants-gov/).

## What is Storybook?

Storybook is an integral part of our product development process, serving as a shared resource for Engineers, Designers, Product Managers, open-source contributors, and other stakeholders.

- **For Engineers:** Develop and test components in isolation without spinning up a full local environment. For internal engineering guidance, refer to the [Mature Storybook Practice and Functionality](https://navasage.atlassian.net/wiki/spaces/Grantsgov/pages/3116531713/2026-05-12+Mature+Storybook+Practice+and+Functionality) page on Confluence.
- **For Designers & Product Managers:** Preview, manually test, and demo the latest versions of components that will be deployed in subsequent production releases.
- **For everyone:** View particular states of the application quickly without navigating through complex, sequential processes (like multi-step web forms).

To get started, explore the custom components and page layouts listed in the menu.

## Storybook is not exhaustive component documentation

We prioritize creating stories that document our custom components and pages. But we don't create stories for every design pattern in the U.S. Web Design System (USWDS) or React component in the ReactUSWDS library. For patterns, styles, and components not covered here, please refer directly to [USWDS documentation](https://designsystem.digital.gov/) and the [ReactUSWDS Component Library](https://trussworks.github.io/react-uswds/). Any guidance documented in this Storybook is meant to supplement those resources.
